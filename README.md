# Little Moments – Family Album

Eigenständige Familienalbum-PWA im warmen Creme-/Braun-Design nach der bereitgestellten Designvorlage.

## Datenschutz
- Eigene IndexedDB: `little-moments-family-album-db`
- Keine Cloud-Synchronisierung und kein Benutzerkonto.
- Fotos und Audioaufnahmen bleiben lokal auf dem Gerät.
- JSON-Backup und Wiederherstellung.

## Veröffentlichung
GitHub Actions Workflow veröffentlicht den Inhalt des Repositorys als GitHub Pages. In den Repository Settings unter Pages als Build and deployment source **GitHub Actions** auswählen.
